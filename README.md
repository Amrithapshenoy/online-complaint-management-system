# Online Complaint Management System

## Overview

A web-based complaint management system designed to allow users to submit and manage complaints through an organized platform with administrator-controlled access.

## Features

* User complaint submission
* Admin-controlled access and management
* Complaint tracking and management
* Telegram bot for emergency notifications to the administrator
* Simple and organized web interface

## Technologies Used

* HTML
* CSS
* Python
* SQL
* Telegram Bot
* VS Code

## Project Highlights

This project provided practical experience in web application development, database-related concepts, problem-solving, and integrating a Telegram bot for emergency notifications.

## Development

The project was implemented using manual coding along with AI-assisted development tools.
